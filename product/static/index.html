数据源

导入订单 / 退款 / 广告

支持 .csv / .xlsx。选择数据类型、读取文件、确认列映射后导入。 勾选“替换整个数据集”会清空旧数据；取消则按主键增量更新。

SKU 映射

订单里的平台商品 ID 与成本表里的商家款号不一致时，在这里建立别名。 保存后会立即重算成本覆盖与亏损 SKU。

导入成本表

支持 .csv / .xlsx。必填：商品编码、生效日期、采购单价；运费、包材可选。 导入后立即重算利润与成本覆盖率。
